Very excited for Emily Heffernan's work on category exception learning to be [published in](https://www.nature.com/articles/s41598-021-00864-9)*[Scientific Reports](https://www.nature.com/articles/s41598-021-00864-9).*In this paper, Emily asked if learning exceptions in a rule-plus-exception category learning task can be significantly improved with a learning sequence that promotes hippocampal encoding. The short answer: yes, in both participants and a neural network model of the hippocampus.
